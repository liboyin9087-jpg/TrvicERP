## Usage in README

To add a screenshot to the README:

```markdown
![Description](screenshots/your-image.png)
```

Or link to GitHub-hosted images:

```markdown
![Description](https://github.com/user-attachments/assets/your-image-id)
```

## File Naming Convention

Use descriptive names for easy identification:
- `configurator-cards.png`
- `erp-dashboard.png`
- `navigator-timeline.png`
- `ai-proposal-example.png`

## Image Guidelines

- Use PNG for screenshots with UI elements
- Use JPG for photographs
- Optimize images for web (keep file size reasonable)
- Consider adding mobile and desktop versions
- Add dark/light mode versions if applicable
