# 台灣團體旅遊業法規知識庫完整彙編

交通部觀光署管轄的台灣團體旅遊產業受到多層次法規體系規範，涵蓋**發展觀光條例**作為母法、**旅行業管理規則**為核心行政命令，以及國內外旅遊定型化契約作為消費者保護基礎。本知識庫完整收錄8大類法規、契約範本與標準作業程序，供AI訓練使用。

---

## 一、核心法規（交通部觀光署）

### 1. 發展觀光條例

| 項目 | 內容 |
|------|------|
| **最新修訂** | 民國114年4月2日 |
| **官方來源** | https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=K0110001 |
| **觀光署連結** | https://admin.taiwan.net.tw/BusinessInfo/Regulation?a=109&id=166 |

**重點條文摘要：**

**第31條（責任保險）**：旅行業辦理旅客出國及國內旅遊業務時，應投保**責任保險**及**履約保證保險**，為本法最重要的保障條款。

**第32條（導遊領隊資格）**：導遊人員及領隊人員應經中央主管機關評量及訓練合格，領取執業證後始得執行業務。

**第53-55條（處罰規定）**：
- 玷辱國家榮譽、損害國家利益、詐騙旅客者：處**3萬至15萬元**罰鍰
- 情節重大者：處**15萬至50萬元**罰鍰
- 未經核准經營旅行業務者：依法勒令停業

### 2. 旅行業管理規則

| 項目 | 內容 |
|------|------|
| **最新修訂** | 民國113年12月27日 |
| **官方來源** | https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=K0110002 |

**第3條（旅行業分類）**：

| 類型 | 資本額 | 保證金 | 履約保證保險 |
|------|--------|--------|--------------|
| 綜合旅行業 | 3,000萬元 | 1,000萬元 | 6,000萬元 |
| 甲種旅行業 | 600萬元 | 150萬元 | 2,000萬元 |
| 乙種旅行業 | 120萬元 | 60萬元 | 800萬元 |

**第23條（團體旅遊規定）**：經營旅客出國團體旅遊業務，於成行前應以書面向旅客作旅遊安全說明或舉辦說明會，成行時**每團均應派遣領隊全程隨團服務**。

**第53條（責任保險投保金額）**─客訴處理核心條款：

| 項目 | 最低金額 | 最高金額 |
|------|----------|----------|
| 每人意外死亡 | **250萬元** | 500萬元 |
| 每人體傷醫療費用 | **10萬元** | 20萬元 |
| 海外善後處理費用 | 10萬元 | - |
| 國內善後處理費用 | 5萬元 | - |
| 證件遺失賠償 | 2,000元 | - |

**第53-1條（履約保證保險）**：
- 加入觀光公益法人（如品保協會）者可降低投保金額
- 綜合旅行業：6,000萬元→**4,000萬元**
- 甲種旅行業：2,000萬元→**500萬元**
- 乙種旅行業：800萬元→**200萬元**

**重點規定：**

- 擅自安排購物收受回扣
- 向旅客額外需索
- 將執業證借供他人使用
- 言行不當

## 二、定型化契約（完整版）

### 1. 國外旅遊定型化契約應記載及不得記載事項

| 項目 | 內容 |
|------|------|
| **最新修訂** | 民國105年9月13日 |

| **PDF下載** | https://www.ey.gov.tw/File/16D8FA2D730D4569?A=C |

#### 📌 第13點 出發前旅客任意解除契約賠償標準（客訴處理核心）

| 解除契約時間 | 賠償旅遊費用比例 |
|-------------|------------------|
| 出發前第**41日**以前 | **5%** |
| 出發前第**31日至第40日** | **10%** |
| 出發前第**21日至第30日** | **20%** |
| 出發前第**2日至第20日** | **30%** |
| 出發前**1日** | **50%** |
| 出發**當日**或出發後/未通知不參加 | **100%** |

**計算說明**：賠償計算基準之旅遊費用，應**先扣除行政規費**後計算。

#### 第12點 因可歸責於旅行業之事由致無法成行

旅行業怠於通知者，應賠償旅客依旅遊費用**全部**計算之違約金。已通知者，按通知到達旅客時距出發日期時間長短計算違約金（比例同第13點）。

#### 不得記載事項

- 行程、住宿、交通、價格、餐飲等內容**不得記載「僅供參考」**
- **不得排除**旅客任意解除、終止契約之權利
- **不得免除或減輕**旅行業依法應履行之義務
- **不得要求**旅客代為攜帶物品返國

### 2. 國外旅遊定型化契約範本

| 項目 | 內容 |
|------|------|

| **觀光署來源** | https://admin.taiwan.net.tw/BusinessInfo/Regulation?a=109&id=193 |

**第14條（法定原因解除契約）**：因不可抗力或不可歸責於雙方之事由，任何一方得解除契約，且不負損害賠償責任。旅行業應提出已支付之必要費用單據，扣除後退還餘款。

**第15條（客觀風險事由解除契約）**：旅遊地區有危害旅客安全之虞時，準用第14條規定，但解除之一方應另按旅遊費用**最多5%**補償他方。

**第31條（未依規定投保處罰）**：未依規定投保者，應以最低投保金額之**3倍**作為賠償金額。

## 三、消費者保護相關

### 1. 消費者保護法

| 項目 | 內容 |
|------|------|
| **最新修訂** | 民國104年6月17日 |
| **官方來源** | https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=J0170001 |

**旅遊業適用重點條文：**

**第11-1條（審閱期）**：企業經營者與消費者訂立定型化契約前，應有合理期間供消費者審閱全部條款內容。

**第12條（顯失公平條款無效）**：定型化契約中之條款違反誠信原則，對消費者顯失公平者，**無效**。

**第17條（應記載/不得記載事項）**：中央主管機關得選擇特定行業，公告規定其定型化契約應記載或不得記載事項。

**第51條（懲罰性賠償金）**─客訴處理重要條款：
- 因企業經營者**故意**所致損害：消費者得請求損害額**5倍以下**懲罰性賠償金
- 因**重大過失**所致損害：得請求**3倍以下**懲罰性賠償金
- 因**過失**所致損害：得請求**1倍以下**懲罰性賠償金

## 四、保險相關法規

### 1. 旅行業責任保險

| 項目 | 內容 |
|------|------|
| **法源依據** | 發展觀光條例第31條、旅行業管理規則第53條 |
| **金管會說明** | https://rm.ib.gov.tw/pages/Insu.aspx?Dir=013000 |

**保障範圍**：旅遊期間內因發生**意外事故**，使旅遊團員身體受傷害因而導致殘廢或死亡或醫療費用。

**重要：疾病死亡及疾病醫療費用不在保障範圍。**

---

### 2. 旅行業履約保證保險

**保障內容**：旅行社在保險期間內，向旅遊團員收取團費後因**財務問題**無法啟程或完成全部行程，致旅遊團員全部或部分團費遭受損失時，由保險公司賠償。

**財務問題定義**：旅行社所有資產不足以清償其債務，遭中央觀光主管機關勒令停業或撤銷旅行業執照。

---

### 3. 強制汽車責任保險（遊覽車適用）

| 項目 | 內容 |
|------|------|
| **法源依據** | 強制汽車責任保險法（民國111年6月15日修正） |
| **官方來源** | https://law.fsc.gov.tw/LawContent.aspx?id=FL006889 |

**給付標準：**

| 項目 | 金額 |
|------|------|
| 死亡給付 | **200萬元/人** |
| 傷害醫療費用給付 | **20萬元/人/事故** |
| 失能給付（第1級） | 200萬元 |
| 失能給付（第15級） | 5萬元 |

---

### 4. 旅行平安保險

| 項目 | 內容 |
|------|------|
| **主管機關** | 金融監督管理委員會 |
| **示範條款** | https://law.fsc.gov.tw/LawContent.aspx?id=FL040188 |

**保障重點**：旅遊期間內因遭受**意外傷害事故**（非由疾病引起之外來突發事故），使身體蒙受傷害而致失能或死亡。

## 五、交通與安全法規

### 1. 汽車運輸業管理規則（遊覽車部分）

| 項目 | 內容 |

#### 第19-2條 駕駛工時限制（客訴處理核心條款）

| 項目 | 規定 |
|------|------|
| 每日最多駕車時間 | **不得超過10小時** |
| 連續駕車時間 | 連續駕車**4小時**，至少應有**30分鐘休息** |
| 休息可分次實施 | 每次不得少於15分鐘 |
| 連續駕車上限 | 最多連續駕車**6小時**，須一次休滿**45分鐘** |
| 兩個工作日之間休息 | 連續**10小時以上**（可調整為8小時，一週以2次為限） |

#### 第84條第3項 單日出租勤務限制

遊覽車客運業車輛出租時，單日出租車輛自車輛報到起至行程結束，調派單一駕駛人勤務**不得逾11小時**。

#### 第19-7條 65歲以上駕駛人特別規定

- 限於**上午6時至下午6時**執行駕駛勤務
- 每日總駕駛時間以**8小時為限**
- 連續駕車**3小時**至少應有30分鐘休息
- 遊覽車客運業限調派其駕駛交通車

#### 第19-4條 GPS監控系統要求

- 自民國106年9月1日起：應裝置**全球衛星定位功能系統設備**
- 自民國**115年1月1日**起：應裝置**駕駛識別功能設備**
- 車輛動態資訊及駕駛人資訊應保存**至少1年**

#### 第86-3條 遊覽車使用年限

- 出廠屆滿**15年**前後一年內，應完成車輛安全查驗
- 完成底盤檢修及車身重新打造：得繼續使用至出廠屆滿**20年**止
- 僅完成底盤檢修：得繼續使用至出廠屆滿**18年**止

## 結論與知識庫應用建議

本知識庫涵蓋台灣團體旅遊業**8大類、超過40項**法規與規範，建構完整的法規架構。對於AI訓練應用，建議優先納入以下**高頻客訴處理條款**：

**取消賠償計算**：國外/國內旅遊定型化契約第13條的賠償比例表（5%→10%→20%→30%→50%→100%）是最常用的客訴處理依據。

**保險理賠範圍**：旅行業責任保險僅保障意外事故，疾病不在保障範圍；戰爭、恐攻、傳染病亦屬除外責任。

**駕駛工時限制**：每日最多駕車10小時、連續駕車4小時須休息30分鐘、單日勤務不得逾11小時，為遊覽車安全的核心規範。

**蒙特婁公約行李賠償**：最新限額為1,519 SDR（約US$2,000），索賠時效為損壞7日、延誤21日內。

建議定期至全國法規資料庫與觀光署行政資訊網確認法規更新，以維持知識庫時效性。
