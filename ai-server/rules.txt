【1. 國外旅遊定型化契約】
================================================================================

■ 契約審閱期（第4條）
- 旅客簽訂契約前，應有至少 1 日之審閱期間
- 旅行社應將契約書攜回審閱
- 未給予審閱期間者，契約條款對旅客不生效力

■ 廣告責任（第5條）
- 旅行社刊登之廣告視為契約之一部分
- 廣告內容與契約不符時，以有利於旅客之解釋為準
- 廣告不得有虛偽不實或引人錯誤之情事

■ 契約應載明事項（第6條）
必須包含：
1. 旅遊地區、行程、起訖地點
2. 旅遊日數、出發日期及時間
3. 交通工具（班機編號、艙等）
4. 住宿旅館名稱、地址、等級
5. 餐飲安排
6. 購物站安排（如有）
7. 自費行程（如有）
8. 領隊、導遊服務
9. 旅遊費用及付款方式
10. 責任保險及履約保險

■ 旅遊費用變更（第8條）
- 契約訂立後，非因可歸責於旅行社之事由，不得變更旅遊費用
- 因匯率、燃油附加費、稅金調整，得於出發前 15 日通知調整
- 調整幅度超過 5% 時，旅客得解除契約

■ 旅客解約退費規定（第13條）【重要】

└─────────────────────┴────────────────┴────────────────┘

■ 不可抗力事由（第15條）
因下列事由解約，雙方互不負賠償責任：
1. 戰爭、暴動、內亂
2. 天災（颱風、地震、海嘯等）
3. 傳染病（需經政府公告）
4. 罷工
5. 政府命令
※ 旅行社應退還已繳費用，扣除已支出之必要費用

■ 行程變更（第16條）
- 旅行社非經旅客同意，不得變更行程
- 不得已變更時，應以同等級替代
- 因變更產生之費用差額，多退少補
- 旅客不同意變更者，得解除契約並請求賠償

■ 購物與自費行程（第17條）
- 購物站：須於契約載明，每日不得超過 1 站
- 自費行程：須事先告知並經旅客同意
- 不得強迫旅客購物或參加自費行程
- 旅客於購物站購買之物品，如有瑕疵，旅行社應協助處理

- 逾期通知，視為旅行社任意解約，應依規定賠償

【3. 旅行業管理規則】
================================================================================

■ 旅行業分類（第3條）
1. 綜合旅行業：可經營國內外團體、個人旅遊
2. 甲種旅行業：可經營國內外團體、個人旅遊
3. 乙種旅行業：僅可經營國內旅遊

■ 保證金規定（第12條）
- 綜合旅行業：NT$ 1,000 萬
- 甲種旅行業：NT$ 150 萬
- 乙種旅行業：NT$ 60 萬

■ 責任保險（第53條）【重要】
旅行業辦理旅遊時，應投保責任保險，最低投保金額：
┌─────────────────────────────┬────────────────────┐
│ 保險項目                    │ 最低保額           │
├─────────────────────────────┼────────────────────┤
│ 每一旅客意外死亡            │ NT$ 500 萬         │
│ 每一旅客因意外所致體傷醫療  │ NT$ 20 萬          │
│ 旅客家屬前往處理善後費用    │ NT$ 10 萬          │
│ 每一旅客證件遺失損害賠償    │ NT$ 2,000          │
└─────────────────────────────┴────────────────────┘

■ 履約保證保險（第53-1條）
- 綜合旅行業：NT$ 4,000 萬
- 甲種旅行業：NT$ 2,000 萬
- 乙種旅行業：NT$ 800 萬

■ 領隊人員規定（第26條）
- 綜合、甲種旅行業辦理團體出國旅遊，應指派領隊
- 領隊須取得領隊人員執業證
- 領隊應全程隨團服務

■ 導遊人員規定（第27條）
- 接待來臺旅客，應指派導遊
- 導遊須取得導遊人員執業證
- 外語導遊、華語導遊應依語言能力指派

■ 禁止事項（第29條）
旅行業不得有下列行為：
1. 以不正當方法招攬旅客
2. 強迫旅客購物
3. 向旅客收取回扣
4. 任意變更行程
5. 將業務轉讓他人經營
6. 僱用未取得執業證之人員執行業務

【4. 消費者保護法（旅遊相關）】
================================================================================

■ 廣告真實義務（第22條）【重要】
- 企業經營者應確保廣告內容之真實
- 對消費者所負之義務，不得低於廣告內容
- 廣告有虛偽不實或引人錯誤者，應負損害賠償責任

■ 定型化契約（第11-17條）
- 定型化契約條款如有疑義，應為有利於消費者之解釋
- 違反誠信原則，對消費者顯失公平者，無效
- 企業經營者不得以定型化契約排除或限制其責任

■ 消費資訊（第24條）
- 企業經營者應主動揭示商品或服務之重要資訊
- 包括：價格、規格、內容、風險、使用方法等

■ 特種買賣（第19條）- 通訊交易
- 消費者得於收受商品後 7 日內退回商品
- 旅遊服務不適用無條件解約權
- 但預購型旅遊商品仍應依定型化契約規定辦理

│ 禁止用語          │ 建議替代用語                       │
├──────────────────┼────────────────────────────────────┤
│ 保證              │ 一般情況下、依實際狀況             │
│ 絕對              │ 通常、多數情況                     │
│ 一定              │ 預期、計畫                         │
│ 100%              │ 高比例、絕大多數                   │

│ 唯一              │ 特色、獨家規劃                     │
│ 永久              │ 長期、持續                         │
│ 無限              │ 豐富、充足                         │
└──────────────────┴────────────────────────────────────┘

■ 價格標示規定
- 應標示全部費用（含稅、含服務費）
- 不得以不實之原價與折扣價進行比較
- 限時優惠應明確標示期限

■ 照片使用規定
- 不得使用與實際不符之照片
- 示意圖應標示「圖片僅供參考」
- 使用他人照片應取得授權

■ 社群媒體行銷
- 業配文應揭露合作關係
- 網紅推薦應標示「合作」或「廣告」
- 假評論、假口碑構成不實廣告

【6. 旅遊保險規定】
================================================================================

■ 旅行業責任保險（強制）
依旅行業管理規則第53條：
- 意外死亡：NT$ 500 萬
- 意外醫療：NT$ 20 萬
- 善後費用：NT$ 10 萬
- 證件遺失：NT$ 2,000

■ 旅行平安保險（建議）
旅客自行投保，建議項目：
- 意外身故及失能：NT$ 500-1,000 萬
- 意外醫療：NT$ 50-100 萬
- 海外突發疾病：NT$ 50-100 萬
- 旅程延誤補償：每 4 小時 NT$ 5,000
- 行李延誤或遺失：NT$ 2-3 萬
- 旅程取消：團費損失賠償

■ 不保事項（常見）
- 戰爭、恐怖攻擊
- 自殺、自傷
- 犯罪行為
- 高風險運動（須加保）
- 既往症（須事先申告）
- 傳染病（依保單約定）

■ 理賠注意事項
- 保留所有收據、診斷證明
- 於時限內通知保險公司
- 配合提供相關文件

■ 護照作業時程
- 一般件：4 個工作日
- 急件：2 個工作日（加收 NT$ 900）
- 最急件：1 個工作日（加收 NT$ 1,200）
- 遺失補發：約 5 個工作日

■ 簽證作業提醒
- 應於出發前確認目的地簽證需求
- 電子簽證應預留 3-5 個工作日
- 落地簽證應備妥相關文件及費用
- 部分國家需「有效來回機票」才能入境

■ 旅客責任聲明
護照效期不足或簽證問題導致無法出境：
- 旅行社已善盡告知義務者，旅客自負責任
- 旅行社未告知者，應負損害賠償責任
- 建議簽署「護照效期確認書」

【8. 團控作業規範】
================================================================================

■ 團次狀態流程
草稿 → 開放報名 → 確認成團 → 團控作業 → 出團 → 結案
       ↓                                    ↓
      取消（未達成團人數）                  結案報告

■ 成團標準
- 最低成團人數：依契約載明（建議 15-20 人）
- 成團確認時間：出發前 7 日
- 未成團處理：
  1. 通知旅客（出發前 7 日）
  2. 全額退費或協調併團
  3. 逾期通知視為旅行社任意解約

■ 人員指派規定
┌──────────────────┬────────────────────────────────────┐
│ 團體類型          │ 人員配置                           │
├──────────────────┼────────────────────────────────────┤
│ 國外團（15人以下）│ 領隊 1 人                          │
│ 國外團（16-30人） │ 領隊 1 人                          │
│ 國外團（31人以上）│ 領隊 1 人 + 協助人員               │
│ 國內團（20人以下）│ 導遊或隨團服務人員 1 人            │
│ 國內團（21人以上）│ 導遊 1 人 + 協助人員               │
└──────────────────┴────────────────────────────────────┘

■ 領隊/導遊津貼標準（參考）
┌──────────────────┬────────────────────────────────────┐
│ 類型              │ 津貼標準                           │
├──────────────────┼────────────────────────────────────┤
│ 國內團領隊        │ NT$ 1,500-2,000/天                 │
│ 國外團領隊（短程）│ NT$ 2,500-3,000/天                 │
│ 國外團領隊（長程）│ NT$ 3,000-4,000/天                 │
│ 專業導遊          │ NT$ 2,000-3,000/天                 │
└──────────────────┴────────────────────────────────────┘

■ 車輛安排規範
- 遊覽車駕駛每日工作不得超過 10 小時
- 連續駕駛 3 小時應休息至少 30 分鐘
- 日本團：司機工時上限 12 小時/天（含休息）
- 歐洲團：依歐盟規定，嚴格執行工時限制

■ 行前說明會
應包含事項：
1. 集合時間、地點、聯絡方式
2. 行程內容、注意事項
3. 目的地天氣、穿著建議
4. 當地法規、習俗禁忌
5. 緊急聯絡方式
6. 保險說明
7. 護照、簽證確認
8. 行李規定

【9. 緊急事件處理】
================================================================================

■ 事件分級
┌──────────────────┬────────────────────────────────────┐
│ 等級              │ 事件類型                           │
├──────────────────┼────────────────────────────────────┤
│ 一級（重大）      │ 死亡、重傷、失蹤、劫持、重大事故   │
│ 二級（嚴重）      │ 住院、財物重大損失、行程嚴重延誤   │
│ 三級（一般）      │ 輕傷、財物遺失、一般客訴           │
└──────────────────┴────────────────────────────────────┘

■ 一級事件處理流程
1. 立即通報公司緊急聯絡人（30 分鐘內）
2. 聯繫當地緊急服務（警察、醫療）
3. 通報我國駐外館處
4. 協助家屬（必要時安排前往）
5. 配合保險理賠
6. 媒體應對（統一由公司發言）
7. 事後檢討報告

■ 醫療緊急處理
1. 確保傷患安全
2. 呼叫當地緊急醫療
3. 聯繫保險公司海外急難救助
4. 協助翻譯、就醫
5. 保留所有醫療文件

■ 護照遺失處理
1. 當地警察局報案取得報案證明
2. 聯繫我國駐外館處
3. 申請入國證明書或臨時護照
4. 協助後續行程安排
5. 申請保險理賠

■ 天災/航班取消處理
1. 確認旅客安全
2. 聯繫航空公司/飯店
3. 安排替代方案
4. 通知公司及旅客家屬
5. 保留相關證明（供後續理賠）

■ 隱藏成本檢查清單【重要】
□ 領隊小費：NT$ 300/天/人（國外團）
□ 司機小費：NT$ 100/天/人（日本團）、€2/天/人（歐洲團）
□ 導遊小費：依當地習慣
□ 飯店行李小費：US$ 1-2/件
□ 床頭小費：US$ 1-2/晚
□ 刷卡手續費：2-3%
□ 營業稅：5%（差額計稅）
□ 匯率緩衝：3-5%（建議預留）
□ 行李超重費
□ 簽證規費
□ 機場稅、燃油附加費
□ 緊急備用金

■ 利潤計算公式
售價 = (Net Cost + 隱藏成本) / (1 - 目標毛利率)

範例：
Net Cost = NT$ 25,000
隱藏成本 = NT$ 2,500
目標毛利率 = 15%

售價 = (25,000 + 2,500) / (1 - 0.15)
     = 27,500 / 0.85
     = NT$ 32,353

■ 毛利率風險評估
┌──────────────────┬────────────────────────────────────┐
│ 毛利率            │ 風險評估                           │
├──────────────────┼────────────────────────────────────┤
│ < 8%             │ ⚠️ 極高風險，強烈不建議接單         │
│ 8-12%            │ ⚠️ 高風險，需嚴格控管成本           │
│ 12-18%           │ ✅ 合理區間                         │

└──────────────────┴────────────────────────────────────┘

【附錄：常見 Q&A】
================================================================================

Q1: 旅客於出發前 15 日取消，應退多少？
A1: 依國外旅遊定型化契約第13條，出發前 2-20 日取消，旅客應賠償 30%，
    旅行社應退還 70%。

Q2: 旅客護照效期只剩 5 個月，可以去日本嗎？
A2: 不建議。日本入境要求護照效期從入境日起算 6 個月以上，
    5 個月可能被拒絕入境。應請旅客換發新護照。

Q3: 廣告上寫「保證入住五星飯店」有問題嗎？
A3: 有風險。「保證」屬於絕對性用語，若因故無法安排五星飯店，
    可能構成廣告不實。建議改為「安排五星級飯店」或「預定五星飯店」。

Q4: 因颱風導致航班取消，旅客要求全額退費，應如何處理？
A4: 依定型化契約第15條，因不可抗力事由取消，雙方互不負賠償責任。
    旅行社應退還已繳費用，但得扣除「已支出之必要費用」（如簽證費、
    保險費、已付且無法退還之訂金等）。

Q5: 旅客在行程中受傷，保險如何理賠？
A5: 旅行業責任保險可理賠因旅行社疏失導致之傷害（最高 NT$ 20 萬醫療）。
    若非旅行社責任，需由旅客自行投保之旅平險理賠。
    建議旅客出發前自行投保旅平險。

Q6: 成本中漏算了小費，已經報價給客人了，怎麼辦？
A6: 若已簽約，原則上不得調漲。建議：
    1. 檢視是否有其他成本可節省
    2. 與旅客協商，說明成本結構
    3. 未來報價務必使用成本檢查清單

Q7: 旅客說同業報價比較便宜，可以降價嗎？
A7: 應分析成本結構，確認是否仍有利潤。寧可不接單也不要虧損出團。
    可強調服務品質、行程內容差異，而非單純比價。
