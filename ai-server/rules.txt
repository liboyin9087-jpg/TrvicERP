# TrvicERP 台灣旅行業法規知識庫
# 版本：1.0.0
# 最後更新：2024

================================================================================
一、旅行業管理規則
================================================================================

【業別分類與資本額】
1. 綜合旅行業：資本額 NT$3,000萬以上
   - 可經營國內外團體、個人旅遊
   - 可委託甲種、乙種旅行業代理招攬

2. 甲種旅行業：資本額 NT$600萬以上
   - 可經營國內外團體、個人旅遊
   - 可委託乙種旅行業代理招攬國內旅遊

3. 乙種旅行業：資本額 NT$300萬以上
   - 僅可經營國內團體、個人旅遊

【保證金】
- 綜合旅行業：NT$1,000萬
- 甲種旅行業：NT$150萬
- 乙種旅行業：NT$60萬
- 設立分公司：每一分公司增繳 NT$30萬

【責任保險】（第53條）
旅行業辦理旅遊時，應投保責任保險，其投保最低金額如下：
1. 每一旅客意外死亡：NT$200萬
2. 每一旅客因意外事故所致體傷之醫療費用：NT$10萬
3. 旅客家屬前往海外或來中華民國處理善後所必需支出之費用：NT$10萬
4. 每一旅客證件遺失之損害賠償費用：NT$2,000

【履約保證保險】
- 綜合旅行業：NT$4,000萬
- 甲種旅行業：NT$1,000萬
- 乙種旅行業：NT$200萬

二、國外旅遊定型化契約
================================================================================

【第13條 - 出發前旅客任意解除契約】
旅客於旅遊活動開始前得解除契約，但應繳交證照費用，並依下列標準賠償：

| 解除時間 | 賠償比例 |
|---------|---------|
| 出發前第41日以前 | 賠償旅遊費用 5% |
| 出發前第31日至第40日 | 賠償旅遊費用 10% |
| 出發前第21日至第30日 | 賠償旅遊費用 20% |
| 出發前第2日至第20日 | 賠償旅遊費用 30% |
| 出發前1日 | 賠償旅遊費用 50% |
| 出發當日或未通知不參加 | 賠償旅遊費用 100% |

【第14條 - 旅行社解除契約】
旅行業於旅遊活動開始前解除契約者，應依下列標準賠償旅客：

| 解除時間 | 賠償比例 |
|---------|---------|
| 出發前第41日以前 | 賠償旅遊費用 5% |
| 出發前第31日至第40日 | 賠償旅遊費用 10% |
| 出發前第21日至第30日 | 賠償旅遊費用 20% |
| 出發前第2日至第20日 | 賠償旅遊費用 30% |
| 出發前1日 | 賠償旅遊費用 50% |
| 出發當日 | 賠償旅遊費用 100% |

【領隊規定】
- 參加國外旅遊團體之旅客人數達一定人數時，旅行業應指派領隊全程隨團服務
- 領隊應專任，不得兼任導遊或其他職務
- 領隊應持有交通部觀光署核發之領隊執業證

三、國內旅遊定型化契約
================================================================================

【第12條 - 出發前旅客任意解除契約】
旅客於旅遊活動開始前得解除契約，但應依下列標準賠償：

| 解除時間 | 賠償比例 |
|---------|---------|
| 出發前第21日以前 | 賠償旅遊費用 10% |
| 出發前第11日至第20日 | 賠償旅遊費用 20% |
| 出發前第4日至第10日 | 賠償旅遊費用 30% |
| 出發前第1日至第3日 | 賠償旅遊費用 70% |
| 出發當日或未通知不參加 | 賠償旅遊費用 100% |

【棄置旅客賠償】
旅行業無正當理由中途棄置旅客時，應賠償旅客被棄置後全部旅遊費用三倍之違約金。

四、導遊人員管理規則 / 領隊人員管理規則
================================================================================

【執業證效期】
- 導遊/領隊執業證有效期間為 3 年
- 期滿前應申請換發
- 換發時需繳交執業證費、體格檢查證明

【24小時通報義務】
導遊/領隊人員於執行業務時，如發生下列情形，應於事件發生後 24 小時內向交通部觀光署通報：
1. 旅客死亡
2. 旅客重傷
3. 旅客失蹤
4. 其他重大事故

【禁止行為】
導遊/領隊人員不得有下列行為：
1. 執行業務時態度惡劣
2. 誘導旅客採購或額外消費
3. 向旅客收取小費之外的費用
4. 安排旅客前往不正當場所
5. 任意變更行程
6. 遺棄旅客或置旅客於危險
7. 與旅行業串通損害旅客權益
8. 將執業證借供他人使用

五、消費者保護法
================================================================================

【審閱期間】
- 企業經營者應給予消費者合理期間審閱定型化契約條款
- 旅遊契約審閱期間至少 1 日（依消保法施行細則）
- 未給予審閱期間，該條款不構成契約內容

【顯失公平】
定型化契約中之條款違反誠信原則，對消費者顯失公平者，無效。
下列情形推定其顯失公平：
1. 違反平等互惠原則
2. 條款與一般交易習慣之約定顯相背離
3. 使消費者負擔過重之責任或義務

【廣告真實性】（第22條）
企業經營者應確保廣告內容之真實，其對消費者所負之義務不得低於廣告之內容。

【懲罰性賠償】（第51條）
依本法所提之訴訟，因企業經營者之故意所致之損害，消費者得請求損害額五倍以下之懲罰性賠償金；
因過失所致之損害，得請求三倍以下之懲罰性賠償金。

六、汽車運輸業管理規則（遊覽車部分）
================================================================================

【駕駛工時限制】
1. 每日行車時間不得超過 10 小時
2. 連續駕車 4 小時，應至少休息 30 分鐘
3. 每日總工作時間不得超過 12 小時

【車輛安全規定】
1. 遊覽車應裝置行車紀錄器
2. 車齡超過 12 年之營業大客車應汰換
3. 應定期實施車輛安全檢查

七、常見問題速查
================================================================================

Q1: 客人出發前15天取消國外團要扣多少？
A1: 依國外旅遊定型化契約第13條，出發前第2日至第20日解約，應賠償旅遊費用30%。

Q2: 導遊/領隊出事故要多久內通報？
A2: 依導遊/領隊人員管理規則，發生旅客死亡、重傷、失蹤或其他重大事故時，應於事件發生後24小時內通報。

Q3: 國內團取消的扣款標準？
A3: 依國內旅遊定型化契約第12條：
   - 21日前：10%
   - 11-20日：20%
   - 4-10日：30%
   - 1-3日：70%
   - 當日/未通知：100%

Q4: 旅行社最低資本額是多少？
A4: 依旅行業管理規則：
   - 綜合旅行業：NT$3,000萬
   - 甲種旅行業：NT$600萬
   - 乙種旅行業：NT$300萬

Q5: 旅行社需要投保哪些保險？
A5: 依旅行業管理規則第53條，需投保責任保險：
   - 意外死亡：每人NT$200萬
   - 體傷醫療：每人NT$10萬
   - 善後費用：每人NT$10萬
   - 證件遺失：每人NT$2,000

Q6: 遊覽車司機一天最多能開幾小時？
A6: 依汽車運輸業管理規則：
   - 每日行車時間不超過10小時
   - 連續駕駛4小時需休息30分鐘
   - 每日總工作時間不超過12小時

Q7: 旅行社可以在廣告中使用「最便宜」嗎？
A7: 不建議。依消費者保護法第22條，廣告內容應真實。使用「最便宜」、「保證」、「絕對」等絕對性字眼可能涉及不實廣告，建議改為「優惠期間」、「視實際狀況」等用語。

Q8: 導遊/領隊執業證多久要換一次？
A8: 依導遊/領隊人員管理規則，執業證有效期間為3年，期滿前應申請換發。

Q9: 旅行社中途棄置旅客要賠多少？
A9: 依國內旅遊定型化契約，旅行業無正當理由中途棄置旅客時，應賠償旅客被棄置後全部旅遊費用三倍之違約金。

Q10: 護照效期要求？
A10: 大多數國家要求從入境日起算，護照效期需有6個月以上。若效期不足，需立即通知旅客更換，若旅客堅持不換，應簽署風險自負切結書。
