# 旅行業管理規則

## 第一章 總則

### 第1條 (定義)
本法所稱旅行業係指經中央主管機關核准，經營旅行業務之事業。

### 第2條 (營業範圍)
旅行業應依核准之營業項目經營，不得超範圍經營。

## 第二章 廣告規範

### 第15條 (廣告真實性)
旅行業刊登廣告，應確保內容真實，不得有虛偽不實或引人錯誤之表示。

#### 禁用詞彙：
- 保證、絕對、一定、100%
- 最低價、最便宜、全台最低
- 無條件退款、隨時退費
- 必成團、鐵定出團

#### 廣告標示要求：
1. 應明確標示價格包含項目
2. 應註明不包含項目及可能增加之費用
3. 應標示出發日期、回程日期
4. 應標示最低成團人數
5. 應標示旅遊責任保險內容

### 第16條 (定型化契約)
旅行業應使用主管機關核定之定型化契約，契約應記載下列事項：

#### 必要記載事項：
1. 旅遊地點、行程、住宿、餐食、交通
2. 旅費包含項目及不包含項目  
3. 旅遊費用、附加費用及可能增加之費用
4. 解約條件及退費標準
5. 旅遊責任保險之投保範圍及金額
6. 緊急聯絡方式及處理程序
7. 旅客應遵守事項及違約責任

## 第三章 解約退費規定

### 第25條 (旅客解約)
旅客於旅遊開始前解約者，旅行社得依下列標準請求賠償：

| 解約時間 | 賠償比例 |
|---------|---------|
| 出發前41日以上 | 旅費5% |
| 出發前31-40日 | 旅費10% |
| 出發前21-30日 | 旅費20% |
| 出發前2-20日 | 旅費30% |
| 出發前1日 | 旅費50% |
| 出發當日 | 旅費100% |

### 第26條 (旅行社解約)
因旅行社過失致旅遊無法進行時，應全額退費並賠償旅客損失。

## 第四章 證照與簽證

### 第35條 (護照效期)
旅行社應提醒旅客護照效期應符合下列要求：
- 一般國家：從入境日起算至少6個月以上
- 部分國家：至少1年（如沙烏地阿拉伯）
- 歐洲申根區：超過預定離境日3個月以上
- 美國：超過預定離境日6個月以上
- 日本：超過預定離境日6個月以上

### 第36條 (簽證責任)
旅行社代辦簽證時應：
1. 審核旅客資料完整性
2. 提供簽證申請須知
3. 告知拒簽風險及後果
4. 協助處理簽證問題

## 第五章 保險規定

### 第40條 (旅遊責任保險)
旅行業應投保旅遊責任保險，保障範圍及最低保額如下：

| 保障項目 | 最低保額 |
|---------|---------|
| 意外死亡 | 新台幣200萬元 |
| 意外傷害 | 新台幣50萬元 |
| 疾病醫療 | 新台幣10萬元 |
| 證件遺失 | 新台幣2萬元 |
| 行李遺失 | 新台幣2萬元 |
| 行李延誤 | 新台幣3千元/日 |

### 第41條 (保險證明)
旅行社應於旅遊開始前將保險證明交付旅客，並記載：
1. 保險公司名稱及保單號碼
2. 保險期間及保險範圍
3. 理賠申請方式及聯絡電話
4. 除外條款及重要事項

## 第六章 營運安全

### 第50條 (領隊資格)
領隊人員應具備：
1. 領隊執照
2. 專業訓練證明
3. 緊急處理能力
4. 語言能力

### 第51條 (緊急處理)
旅行社應建立緊急處理程序：
1. 24小時緊急聯絡電話
2. 醫療緊急處理流程
3. 事故通報程序
4. 協助旅客聯繫家人機制

## 第七章 罰則

### 第60條 (違規處罰)
違反本法規定者，主管機關得處：
- 新台幣5萬元以上100萬元以下罰鍰
- 命其限期改正
- 情節重大者得廢止其營業許可

### 第61條 (民事責任)
因違規造成旅客損害者，應負賠償責任。
