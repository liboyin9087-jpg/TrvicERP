【一、國外旅遊定型化契約應記載及不得記載事項】

## 第13條 旅客任意解除契約

旅客於旅遊活動開始前得通知旅行社解除本契約，但應繳交行政規費，並依下列標準賠償旅行社：

| 通知日期 | 賠償比例 |
|---------|---------|
| 旅遊開始前第41日以前 | 旅遊費用 5% |
| 旅遊開始前第31日至第40日 | 旅遊費用 10% |
| 旅遊開始前第21日至第30日 | 旅遊費用 20% |
| 旅遊開始前第2日至第20日 | 旅遊費用 30% |
| 旅遊開始前1日 | 旅遊費用 50% |
| 旅遊開始日或開始後 | 旅遊費用 100% |

備註：
- 「行政規費」指簽證費、機場稅等實際支出且無法退還之費用
- 旅客未通知不參加者，視為旅遊開始日解除契約

## 第14條 旅行社任意解除契約

旅行社於旅遊活動開始前解除契約者，應賠償旅客，標準如下：

| 通知日期 | 賠償比例 |
|---------|---------|
| 旅遊開始前第41日以前 | 旅遊費用 5% |
| 旅遊開始前第31日至第40日 | 旅遊費用 10% |
| 旅遊開始前第21日至第30日 | 旅遊費用 20% |
| 旅遊開始前第2日至第20日 | 旅遊費用 30% |
| 旅遊開始前1日 | 旅遊費用 50% |
| 旅遊開始日或開始後 | 旅遊費用 100% |

## 第15條 因可歸責於旅行社之事由解除契約

因可歸責於旅行社之事由，致旅遊活動無法成行者：
- 旅行社應即通知旅客並說明事由
- 旅行社應退還旅客已繳全部費用
- 旅行社並應賠償旅客相當於旅遊費用之違約金

## 第27條 不可抗力或不可歸責事由

因不可抗力或不可歸責於雙方當事人之事由，致契約無法履行者：
- 旅行社應退還旅客已繳費用，但得扣除已代繳之行政規費
- 任一方不負損害賠償責任

不可抗力事由包括：天災、戰爭、暴動、罷工、政府行為（含航班取消）、傳染病等

【二、國內旅遊定型化契約應記載及不得記載事項】

## 第12條 旅客任意解除契約

| 通知日期 | 賠償比例 |
|---------|---------|
| 旅遊開始前第21日以前 | 免賠償 |
| 旅遊開始前第11日至第20日 | 旅遊費用 10% |
| 旅遊開始前第4日至第10日 | 旅遊費用 30% |
| 旅遊開始前第1日至第3日 | 旅遊費用 50% |
| 旅遊開始日或開始後 | 旅遊費用 100% |

## 第13條 旅行社任意解除契約

賠償標準同第12條

【三、旅行業管理規則重點摘要】

## 第53條 責任保險

旅行業辦理旅遊業務，應投保責任保險，其最低投保金額如下：

| 保障項目 | 最低保額 |
|---------|---------|
| 每一旅客意外死亡 | NT$250萬元 |
| 每一旅客因意外事故所致體傷之醫療費用 | NT$10萬元 |
| 旅客家屬前往海外處理善後所必需支出之費用 | NT$10萬元 |
| 國內旅遊善後處理費用 | NT$5萬元 |
| 每一旅客證件遺失之損害賠償費用 | NT$2,000元 |

## 第49條 旅行業類別

| 類別 | 經營範圍 |
|-----|---------|
| 綜合旅行社 | 國內外旅遊、代辦出入國手續、代售日常生活所需陸上/海上/航空客票 |
| 甲種旅行社 | 接待國內外觀光旅客、國內外旅遊、代辦出入國手續 |
| 乙種旅行社 | 僅限國內旅遊 |

【五、個人資料保護法重點】

## 蒐集、處理、利用個人資料之告知義務

旅行社蒐集旅客個資時，應告知：
1. 蒐集機關名稱
2. 蒐集之目的
3. 個人資料之類別
4. 個人資料利用之期間、地區、對象及方式
5. 當事人依法得行使之權利及方式
6. 當事人得自由選擇提供個人資料時，不提供將對其權益之影響

## 違規罰則

| 違規情節 | 罰則 |
|---------|-----|
| 一般違規 | NT$2萬至200萬元 |
| 限期未改正或情節重大 | NT$15萬至1,500萬元 |
| 每人每一事件損害賠償 | NT$500至2萬元 |
| 同一事件最高賠償總額 | 2億元 |
| 意圖營利而違法 | 5年以下有期徒刑 |

【六、常見問答 FAQ】

Q1: 旅客出發當天未出現（No Show），可以退費嗎？
A1: 依國外旅遊定型化契約第13條，旅遊開始日或開始後解除契約，旅客應賠償旅遊費用100%，即不予退費。

Q2: 因颱風導致班機取消，如何處理？
A2: 屬不可抗力事由（第27條），旅行社應退還已繳費用，但得扣除已代繳無法退還之行政規費（如簽證費、機場稅）。雙方互不負損害賠償責任。

Q3: 旅客報名後發現懷孕不適合搭機，可以全額退費嗎？
A3: 懷孕屬旅客個人因素，非不可抗力事由，仍依第13條賠償標準處理。建議旅客購買旅遊不便險以降低損失。

Q4: 旅行社因人數不足取消出團，要賠多少？
A4: 依第14條，若旅行社於出發前1日通知取消，應賠償旅遊費用50%；若出發當日才通知，應賠償100%。

Q5: 領隊/導遊小費是否包含在團費內？
A5: 除非契約明確載明「小費全包」，否則小費屬額外支出。建議於報價單明確標示小費收取標準。

Q6: 旅客在國外受傷，旅行社責任範圍？
A6: 旅行社依第53條已投保責任保險，每一旅客體傷醫療最低保額10萬元。超出部分視事故責任歸屬判定。

Q7: 旅客護照效期不足被拒絕登機，誰負責？
A7: 旅行社有告知義務，若已於行前說明會或書面通知提醒護照效期需6個月以上，且旅客自行疏忽未更新，責任在旅客。

Q8: 企業團要求開立統一發票，稅金如何計算？
A8: 代收轉付項目（機票、食宿、門票等）不計入銷售額，差額部分需開立統一發票並課徵5%營業稅。
